# MetaWriters Page — Design Prompt

Design a professional, modern, academic interface for **MetaWriters**, a service where users submit scientific writing — manuscripts, abstracts, papers, and related files — to be corrected by a specialized team.

## Main MetaWriters Page

Create a landing page that clearly explains what MetaWriters is.

The hero section should have a **side-by-side layout**:

- **Left side:** video area explaining the service.
- **Right side:** concise text explaining that users can submit scientific materials for correction by the MetaWriters team.
- Include a strong call-to-action button: **“Submit your work”**.

Add an animated statistics section showing the impact of the service, using polished counters, cards, or motion effects.

Suggested stats:

- Papers/manuscripts corrected
- Abstracts corrected
- Average satisfaction score
- Average turnaround time
- Number of reviewers/correctors

The visual style should feel **academic, trustworthy, clean, premium, and organized**, not generic or overly flashy.

## Submission / Dashboard Page

When the user clicks **Submit your work**, they should go to a submission dashboard.

This page must include:

### New Submission

A clear area or button to submit a new work, including file upload for manuscripts, abstracts, papers, and related documents.

### Past Submissions

Show previous submissions in a carousel or clean card-based layout.

Each submission card should display:

- Submission title or identifier
- Date sent
- Uploaded files
- Expected return date
- Current status
- Assigned reviewer/corrector
- Returned/corrected files, when available

Use clear status badges such as:

- Submitted
- Assigned
- In review
- Returned
- Completed

### Support

Add a visible button for problems or questions.

The button should let the user contact **Morgado**, who is responsible for handling MetaWriters issues.

Suggested label:

**“Need help? Contact Morgado”**

### Rating

Add a simple rating section so users can evaluate the MetaWriters service after receiving their corrected work.

Include:

- Star rating
- Optional short feedback box

## Important Notes

Corrected files should be accessible inside the platform, even if they are also sent by WhatsApp by the person who corrected them.

Prioritize:

- Clear UX
- Beautiful animations
- Academic/professional credibility
- Easy submission flow
- Easy visualization of past submissions
- Trust and transparency about who is correcting each work
